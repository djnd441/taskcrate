# 数据恢复指引

## 备份文件位置

应用会自动将数据库快照保存到数据目录下的 `backups` 文件夹，文件名格式为：

```text
task-manager-backup-YYYYMMDD-HHMMSS.db
```

默认保留最近 10 份备份。也可以在“设置 - 自动备份”中点击“立即备份”手动生成一份。

## 恢复步骤

1. 完全关闭“TaskCrate”应用。
2. 打开备份目录，选择最新的 `.db` 文件。
3. 将该文件复制到数据目录，并覆盖 `task-manager.db`。
4. 重新启动应用。

## 数据库损坏处理

如果启动或操作时出现“数据库错误”，请先不要删除原始文件，按以下顺序处理：

1. 将数据目录中的 `task-manager.db`、`task-manager.db-wal`、`task-manager.db-shm` 复制到其他文件夹。
2. 使用最新备份按“恢复步骤”恢复。
3. 若无可用备份，将原始损坏文件保留，便于后续尝试使用 SQLite 工具修复。

## 导入导出

“设置 - 数据与恢复”支持：

- 导出 JSON：全量备份项目、标签、任务与设置。
- 导出 CSV：通用表格格式，便于 Excel/WPS 打开。
- 导入 JSON：可选择文件，也可粘贴 JSON 内容；合并模式保留现有数据，覆盖模式替换数据。
