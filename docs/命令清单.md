# Tauri Command 清单

## 健康与设置

| 命令 | 说明 |
| --- | --- |
| `health_check` | 应用版本、schema 版本、数据目录 |
| `get_settings` / `update_settings` | 读取/更新设置 |

## 项目与标签

| 命令 | 说明 |
| --- | --- |
| `list_projects` / `get_project` | 项目列表/详情 |
| `create_project` / `update_project` | 新建/编辑项目 |
| `archive_project` / `delete_project` | 归档/删除项目 |
| `list_tags` / `get_tag` | 标签列表/详情 |
| `create_tag` / `update_tag` / `delete_tag` | 标签 CRUD |

## 任务

| 命令 | 说明 |
| --- | --- |
| `list_tasks` / `get_task` | 组合筛选、排序、分页 |
| `create_task` / `update_task` | 新建/编辑任务 |
| `transition_task_status` | 状态机流转 |
| `archive_task` / `unarchive_task` | 归档/取消归档 |
| `soft_delete_task` / `restore_task` / `hard_delete_task` | 回收站操作 |
| `list_due_reminders` | 查询到期提醒任务 |

## 批量操作

| 命令 | 说明 |
| --- | --- |
| `batch_complete_tasks` | 批量完成 |
| `batch_soft_delete_tasks` | 批量移入回收站 |
| `batch_restore_tasks` | 批量恢复 |
| `batch_hard_delete_tasks` | 批量彻底删除 |
| `batch_set_priority` | 批量设置优先级 |
| `batch_set_project` | 批量移动项目 |
| `batch_add_tags` | 批量添加标签 |
| `clear_trash` | 清空回收站 |

## 备份、导入导出

| 命令 | 说明 |
| --- | --- |
| `backup_now` | 立即备份数据库 |
| `list_backups` | 备份目录与最近备份列表 |
| `export_json` | 导出 JSON 全量备份 |
| `export_csv` | 导出 CSV |
| `import_json` | 从文件导入 JSON |
| `import_json_text` | 从文本导入 JSON |

## 帮助

| 命令 | 说明 |
| --- | --- |
| `check_update` | 检查当前版本与更新源状态 |
