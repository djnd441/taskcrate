## 修复 2（2026-08-06）

### 问题

- 新建任务弹窗输入一个字符后自动失焦，需要重新点击文本框

### 根因

- Modal 的焦点管理 effect 依赖了内联 `onClose`
- 每次输入触发父组件重渲染后，effect 重新执行并把焦点从输入框抢到 Modal 容器

### 修复

- Modal 使用 ref 保存最新 `onClose`，effect 仅依赖 `open`
- 存在 `autoFocus` 输入框时不聚焦 Modal 容器

### 验证

- 新增“输入过程中焦点始终停留在文本框”e2e
- Playwright e2e：19 项通过

## 修复 3（2026-08-07）

### 问题

- 列表界面出现红色提醒：`invalid args 'filter' for command 'list_tasks': missing field 'includeArchived'`

### 根因

- Rust 端 `TaskFilter` 的 `includeArchived/includeDeleted` 为必填字段，前端筛选对象经常不传这两个字段

### 修复

- Rust 端 `TaskFilter` 增加 `#[serde(default)]`，缺失字段自动默认为 `false`
- 前端 `listTasks` 统一补齐 `includeArchived: false`、`includeDeleted: false`
