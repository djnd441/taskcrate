# 双端兼容报告

## 验证范围

Phase 5 只做电脑端优先架构的移动端预留验证，不开发手机端专属功能。

## 1. Web 预览形态

新增 `apps/web`，复用 `packages/domain`、`packages/ui` 与桌面端 React 视图。

- 启动：`pnpm web:dev`，访问 `http://127.0.0.1:1421`
- 构建：`pnpm web:build`
- 存储：Web 预览使用 IndexedDB 适配器，刷新页面后数据不丢失
- 验证：e2e 已覆盖“创建任务后刷新页面仍存在”

## 2. 触屏交互映射

| 桌面操作 | 移动端替代 |
| --- | --- |
| 看板拖拽 | 保留拖拽，同时提供卡片“更多”菜单，可一键移动到任意状态/项目 |
| 右键菜单 | 所有常用操作均提供可见按钮或菜单 |
| 悬停显示操作 | 列表操作按钮常显；看板卡片提供常显“更多”按钮 |
| 复选框 | 触控目标高度提升至 36px |

## 3. 通知适配层

`apps/desktop/src/notifications/notifier.ts` 定义统一接口：

- `desktop`：Tauri Notification 插件
- `web`：浏览器 Notification
- `push`：仅保留契约，尚未实现，供后续移动端接入

## 4. 断点与触控目标

- 375px 宽度下无横向溢出
- 侧栏可打开/关闭
- 导航、按钮、复选框触控目标可用
- 桌面三档断点：≥1200 / 768-1199 / <768

## 结论

同一套 domain + ui + 视图代码可在桌面端与 Web 预览运行；IndexedDB 数据可持久化；触屏替代操作已覆盖；手机端功能未开发。
