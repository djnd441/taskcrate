# 数据模型

## 表结构

### projects

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT PK | 项目 ID |
| name | TEXT | 项目名称 |
| color | TEXT | 项目颜色 |
| sort_order | INTEGER | 排序 |
| is_archived | INTEGER | 是否归档 |
| created_at / updated_at | TEXT | 时间戳 |

### tags

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT PK | 标签 ID |
| name | TEXT UNIQUE | 标签名称 |
| color | TEXT | 标签颜色 |
| created_at | TEXT | 创建时间 |

### tasks

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT PK | 任务 ID |
| title | TEXT | 标题 |
| notes | TEXT | 备注 |
| due_at | TEXT | 截止时间 |
| priority | TEXT | none/low/medium/high/urgent |
| status | TEXT | todo/in_progress/completed/cancelled |
| project_id | TEXT FK | 所属项目 |
| sort_order | INTEGER | 排序 |
| archived_at | TEXT | 归档时间 |
| created_at / updated_at | TEXT | 时间戳 |
| completed_at | TEXT | 完成时间 |
| deleted_at | TEXT | 软删除时间 |
| schema_version | INTEGER | 数据版本 |

### task_tags

任务与标签多对多关系表，主键为 `(task_id, tag_id)`。

### settings

键值表，保存主题、提醒、备份频率、数据目录、最近备份时间等设置。

## 状态机

```text
todo <-> in_progress
todo -> completed
todo -> cancelled
in_progress -> completed
in_progress -> cancelled
completed -> todo
cancelled -> todo
```

非法流转会被 Rust 状态机拒绝，例如 `completed -> cancelled`。

## 生命周期

```text
创建 -> 待办 -> 进行中 -> 已完成 -> 重新打开 -> 待办
                 -> 归档 / 软删除（回收站） -> 恢复 / 彻底删除
```
