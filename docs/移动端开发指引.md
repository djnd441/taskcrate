# 移动端开发指引

## 接入路线

移动端有两种推荐路线：

1. Tauri Mobile（Android/iOS）
   - 保留现有 Rust 数据层与 command 层
   - 新增移动端 Adapter，继续调用同一套 command
   - 使用 `pnpm tauri android init` / `pnpm tauri ios init`

2. Web 容器 / PWA
   - 使用现有 `apps/web` 预览包
   - IndexedDB 已可持久化，可直接作为本地存储
   - 通过 PWA 或 WebView 容器分发

## 复用清单

- `packages/domain`：模型、Repository 端口、状态机
- `packages/ui`：组件与设计令牌
- `apps/desktop/src/App.tsx` 与四个视图
- `apps/desktop/src/adapters`：桌面 / Web 适配器切换机制
- `apps/desktop/src/notifications/notifier.ts`：通知统一接口

## 需要新增

- 移动端专属布局：底部导航、全屏详情页、大触控按钮
- 移动端 Adapter：调用 Tauri Mobile command 或 IndexedDB
- Push 通知实现：当前只有契约，未接入厂商推送
- 跨设备同步：当前数据仅本地保存，无同步后端
- 文件选择与备份：Web 端文件能力受浏览器限制，移动端需使用系统文件 API

## 已知限制

- SQLite 数据仅存在于当前设备，未做云同步
- 桌面通知与移动端 Push 不互通
- 移动端拖拽依赖触屏手势，建议以菜单操作为主
- 首次移动端开发前需重新评估打包、签名与权限

## 建议顺序

1. 使用 `apps/web` 验证移动端布局与交互
2. 接入 Tauri Mobile 壳
3. 补齐移动端 Adapter 与文件能力
4. 接入 Push 通知
5. 按需求 backlog 逐步增加手机端功能
