# 构建与发布说明

## 构建安装包

```powershell
cd <项目根目录>
$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"
pnpm --filter @task-manager/desktop tauri build
```

产物位置：

```text
apps/desktop/src-tauri/target/release/bundle/nsis/TaskCrate_0.1.0_x64-setup.exe
```

## 安装与卸载

- 双击安装包即可安装，默认安装到当前用户目录。
- 可通过“开始菜单”或安装目录中的 `uninstall.exe` 卸载。
- 静默安装：`TaskCrate_0.1.0_x64-setup.exe /S`
- 静默卸载：`uninstall.exe /S`

## 性能基准

在 release 模式下以 SQLite 插入 1 万条任务后的实测数据：

| 项目 | 实测 | 目标 |
| --- | --- | --- |
| 数据库打开 + 迁移 | 1ms | < 3000ms |
| 关键词搜索 | 4ms | < 200ms |
| 列表读取 1000 条 | 6ms | < 200ms |
| Web 预览 1 万条渲染 | 约 65ms（模块热身后） | 流畅可用 |
